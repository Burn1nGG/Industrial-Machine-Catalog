# Industrial Machine Catalog

Desktop Windows-приложение для поиска, учета и управления каталогом промышленного оборудования на предприятии.

---

## 📌 Краткое описание

**Industrial Machine Catalog** предназначено для оперативного поиска и просмотра карточек станков и промышленного оборудования. Приложение позволяет:
- Быстро фильтровать и находить оборудование по цеху, учетному/инвентарному номеру, модели, производителю и типу.
- Просматривать подробную карточку оборудования с техническими характеристиками, паспортными данными и статусом эксплуатации.
- Напрямую открывать сетевые и локальные папки с документацией и чертежами оборудования в Проводнике Windows (`FolderRouter` поддерживает сетевые диски `S:\`, UNC-пути и фоллбэки).
- Настраивать параметры подключения к БД и хранилищу через удобный интерфейс с поддержкой демо-режима при отсутствии связи с PostgreSQL.

---

## 🛠 Стек технологий

* **Язык программирования:** Python 3 (3.10+)
* **Графический интерфейс (GUI):** [PySide6](https://pypi.org/project/PySide6/) (Qt 6 for Python) — с поддержкой High DPI масштабирования и единой стилевой темой.
* **База данных / СУБД:** PostgreSQL (драйвер `psycopg2` / `RealDictCursor`, поддержка схемы `equipment.*`).
* **Сборка и дистрибуция:** PyInstaller (автономный исполняемый `.exe` файл для Windows).
* **Тестирование:** `pytest` / `unittest`.
* **Формат конфигураций:** JSON (`config.json`).

---

## 📂 Структура проекта

* `main.py` — Точка входа в приложение, инициализация `QApplication` и главное окно.
* `db_manager.py` — Модуль работы с PostgreSQL (подключение, выполнение запросов, обработка ошибок, демо-режим).
* `folder_router.py` — Модуль навигации по файловой системе и файловым серверам предприятия (открытие папок документации).
* `build_exe.py` — Скрипт сборки приложения в бинарный файл `EquipmentCatalog.exe`.
* `config.json` — Файл настроек подключения к БД и путей хранилища.
* `ui/` — Компоненты графического интерфейса:
  * `main_window.py` — Главное окно со списком оборудования и панелью фильтров.
  * `detail_card_dialog.py` — Диалоговое окно детальной карточки оборудования.
  * `db_settings_dialog.py` — Диалог настройки параметров БД и сетевого диска.
  * `styles.py` — Стили оформления виджетов (QSS/CSS).
* `database/` — DDL-скрипты базы данных (`schema.sql`), тестовые данные (`seed_data.sql`) и утилита инициализации (`init_db.py`).
* `tests/` — Юнит-тесты и проверки совместимости схемы БД.

## 🚀 Запуск и сборка

### Запуск из исходного кода
```bash
python main.py
```

### Запуск тестов
```bash
pytest
```

### Сборка `.exe` файла
```bash
python build_exe.py
```
